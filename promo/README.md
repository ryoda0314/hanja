# ことのね — 紹介映像

アプリの映像。1920×1080・30fps・約111秒、字幕とナレーション（Gemini TTS）。Remotion 4 で作る（アプリとは別のプロジェクト）。
作り方は姉妹アプリ ことのは の映像（`../../english/promo`）にそろえた：アプリの画面を描き直し、その横に一文ずつ言葉を置く。

見る人：韓国語の単語を一つずつ丸暗記していて、「漢字の読みを一字ずつ覚えると、組み合わせるだけで単語が作れる」
「野球が 야구、体育が 체육 なら、球体は 구체」という覚え方に目を開かれた人たち。その覚え方が、そのままアプリになって
いることを見せる。

漢字は日本の字で見せる（日本の人に向けたアプリなので）。アプリの 漢字の字形 を「日本の字」にしたときの画面で、
學・會・體 のような韓国の字形は出さない。

数はアプリの辞書のとおり。会・社・員 の3字でできる語は 회사・사회・회원・사원・회사원 の5語。網の21字
（会社員学生先校大中国語韓日本人外民時間電話）だけでできる語は72語で、アプリが「読める語」に数えるのと同じ決まり
（2字以上、字がすべて集めた字）。網で言葉の札を出すのは、そのうちよく使う語（krdict の 初級〜高級）だけ。ほかの語も
線は光り、数には入る。학생・대학・회사・사회・회원 を集めた人が 야구 をあつめると +1（야생）、체육 で +4（구체・대체・생육・생체）。
覚え具合とふりかえりの日はアプリの `src/data/stage.ts` のとおり：あつめた → また出会った（集めた日とは別の日に、文の中で）→
読めた（漢字からハングルを、答えを見ずに）→ 身についた（別の日に、もう一度読めた）。次のふりかえりは あつめた 1日後・
また出会った 2日後・読めた 6日後・身についた 20日後から、読めるたびに倍（120日まで）。

## ナレーション

台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文）。日本語の語りに、韓国語の語（회사・사회…、학생・선생…、
체육、구체）が韓国語の発音で入る。韓国語の語は、画面にその語が出る時に一つずつ鳴る。

- 声：Gemini TTS（`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。鍵は ことのは と同じサービスアカウント
  （`GOOGLE_SERVICE_ACCOUNT_KEY`・`GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`）。鍵はこのリポジトリに置かない。
- 映像の時は、声の長さから決まる（`src/voice.json`。`src/timeline.ts` は声が言い終わってから次へ進む）。声を作り直したら
  `music` も走らせ直す。声のあいだは音楽が下がる（`src/Promo.tsx` の DUCKING）。
- 韓国語の語ひとつは、ときどき別の語になる・語を足す（일본어 → 친구、구체 → 구체적으로 になった）。生成器は書き起こし
  （`gemini-2.5-pro`）が台本の語と一致するまで作り直す。日本語の行は `--check` で書き起こして台本と並べて見る。
- 耳で聞いての確かめ（声の感じ・速さ・韓国語の発音の自然さ）は、機械ではできない。

## ホーム画面への追加のしかた（src/Install.tsx）

X のリンクから開いた人は、X の中のブラウザで開いている。そこではホーム画面に追加できないので、まず Safari（Android は
Chrome）で開き直し、それから追加する。iPhone（下のアドレスの「⋮」→「ブラウザで開く」→ Safari のアドレス欄の左はしの「≡」→「共有」→
「表示を増やす」→「ホーム画面に追加」→「追加」）、Android（下のアドレスの「⋮」→「ブラウザで開く」→ Chrome の右上の「⋮」→「ホーム画面に追加」→
「インストール」）の順に、指で押すところを見せる。メニューに見つからないときは、リンクをコピーしてアドレス欄に貼り付ける。
X の中のブラウザは 2026年10月の iPhone の画面に合わせた（ページは画面いっぱい、下に ✕・「vercel.app ⋮」・読み込み直し、
その下に投稿の帯。「⋮」のメニューは 共有する・ブラウザで開く・リンクをコピー）。Safari も iOS 26 の画面に合わせた
（共有シートの「ホーム画面に追加」は「表示を増やす」の中）。共有シートの人とアプリは形だけ（だれかの写真やロゴは描かない）。
Android の X と Chrome は確かめていない（X は iPhone と同じ形と見なしている）。

- 縦の映像。X の自動再生は音なしなので、説明はすべて字幕にも出す。ナレーションは `voice/lines.json` の I01〜I17
  （I03 は欠番）で、映像の時は声の長さから決まる（`src/Install.tsx` の make()：指で押すのは、声が「押して」「選びます」と
  言うところ）。声のあいだは音楽が下がる。サファリ・クローム・エックス・アイフォーン は仮名で台本に書く。
- X・Safari・Chrome の画面は形だけをまねた絵で、ロゴは描かない。メニューの言葉は版によって違う（X の「…」の中身、
  Chrome の「ホーム画面に追加」と「アプリをインストール」）ので、字幕で「〜と出ることもあります」と添えている。
  iOS・Chrome が大きく変わったら、`Safari`・`Chrome`・`InAppBrowser` の絵と字幕（STEPS）を合わせる。

## 作り方

```bash
cd promo
npm install
npm run net        # 冒頭の字の網（アプリの辞書 ../public/data から src/net.json を作る）
npm run assets     # アプリのアイコンと字（Google Fonts の倉庫から取り、映像に出てくる字だけに切る。Python の fontTools）
npm run voice -- --env ../../../english/.env.local   # ナレーション（まだ無いクリップだけ。--force・--only V01,K01・--check）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/kotonone-promo.mp4
npm run card       # 一目でわかる紹介画像 out/kotonone-card.png（1920×1080。src/Card.tsx）
npm run install-video   # ホーム画面への追加のしかた out/kotonone-install.mp4（縦 1080×1920・約93秒。src/Install.tsx）
npm run stills -- 300 1150     # 1コマだけ out/stills に（COMP=Install でホーム画面への追加のしかたから）
```

- 画面はアプリの CSS と文言から描き直している（`src/ui.tsx`、`src/scenes/`）。アプリの見た目や言葉を変えたら、ここも変える。
- いつ何が起きるかは `src/timeline.ts`。打つ長さは打ち方（`src/anim.ts` の koTyping）から決まる。時を変えたら `music` を
  走らせ直す（音楽の最後の和音が終わりのカードに落ちる）。
- 字はアプリと同じ（IBM Plex Sans JP・IBM Plex Sans KR・Noto Serif KR・しっぽり明朝）。言葉を変えたら `assets` を走らせ直す。
- 音楽と小さな音は `scripts/music.py` が作る（ことのは の映像と同じ作り方）。だれかの曲は使っていない。
- 色は `remotion.config.ts` で bt709・yuv420p にしている。Remotion の既定（JPEG のコマ）のままだと全範囲の yuvj420p に
  なり、ブラウザや X で薄い灰色が白く飛ぶ。
